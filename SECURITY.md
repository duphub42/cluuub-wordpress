# Security policy

Please do not publish exploitable vulnerability details in a public issue.

Use GitHub's **Report a vulnerability** option on this repository's Security tab for a private report. If that option is unavailable, contact cluuub support at [support@cluuub.app](mailto:support@cluuub.app) and include the repository name, affected version, impact, and reproducible steps. Do not include member data, passwords, API keys, or other secrets.

This project is an early integration. The plugin only reads public showcase data; changes that add credentials, personal-data submissions, or arbitrary script execution require a separate security review.
