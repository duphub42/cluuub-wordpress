# Changelog

Notable changes to cluuub Embed for WordPress.

## 0.2.1

- Make the public cluuub credit link optional and disabled by default.
- Clarify external service requests and privacy behavior for directory review.

## 0.2.0

- Add the public cluuub showcase API integration.
- Add a dynamic Gutenberg block and `[cluuub]` shortcode.
- Support activities, coaches, venues, board contacts, and sponsors.
- Add a five-minute transient cache and responsive card styling.
- Add privacy disclosure, security notes, and automated checks.
